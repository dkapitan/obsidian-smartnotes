# Navigation

## Indices
#index Adds a note to the alphabetic index. Useful for one-word titles.
#person Adds a note to the name-register. 

## Hubs
#hub Indicates a permanent note that became a hub for other notes; in its simples form it is just the first note in a note-sequence, an „entry-note“. 
#hub/moc Indicates a hub that became a hub for other hubs (a higher order hub). 
These notes should be listed on the starting page or respective area of interest. 


> [!Tip] Specify the area of interest this project belongs to
> Specify the area of interest with its number behind "area::"

## Regular permanent notes
Tip: It often makes sense to indicate the "previous" or "higher order" note a new note belongs to on a separate line beginning with "up::". This is automatically added when notes are spun-off with the help of the "note-refactor" add-on.

# Title markers

## Permanent Notes
- "NoteTitle +" (note with #hub   tag, which serves as an "entry note" into a note-sequence or a hub for other notes; usually a descriptive title)
- NoteTitle ++ (the same, only more developed, usually with curated link collection, some or all of them to other MOC's)

## Project notes
- "WP NoteTitle" (note with #project tag; in project folder)
