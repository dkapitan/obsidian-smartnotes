> [!tip] Simply open the menu via Ctrl+P for quick access to all commands 
> (whenever you cannot remember the hotkey or would like to assign a new hotkey)

 #### General
| Win                 | Mac       | Action                       |
| ------------------- | --------- | ---------------------------- |
| Ctrl + Shift + F    | ⌘ + ⇧ + F | Search in all files          |
| Ctrl + F            | ⌘ + F     | Search in current file       |
| Ctrl + G            | ⌘ + G     | Open graph view              |
| Ctrl + ,            | ⌘ + ,     | Open settings                |
| Ctrl + P            | ⌘ + P     | Open menu                    |
| Alt + Shift + left  | ⌥ + ⇧ + ← | Toggle left sidebar          |
| Alt + Shift + right | ⌥ + ⇧ + → | Toggle right sidebar         |
| Ctrl + M            | ⌘ + M     | Toggle Todo/Done/Bulletpoint |
|                     |           |                              |
### Editing
| Win                  | Mac          | Action                              |
| -------------------- | ------------ | ----------------------------------- |
| Ctrl + D             | ⌘ + D        | Delete current line                 |
| Ctrl + V             | ⌘ + V        | Duplicate currenct line             |
| Ctrl + Click         | ⌘ + Click    | Open Note in Current Panel via Link |
| Ctrl + Shift + Click | ⌘ +⇧ + Click | Open Note in New Panel via Link     |

#### Citation
| Win              | Mac       | Action                               |
| ---------------- | --------- | ------------------------------------ |
| Ctrl + Shift + E | ⌘ + ⇧ + E | Insert literature note link          |

#### Format

| Syntax | Result            | Notes                                                                                                                                                                      |
| ------ | ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **     | **Bold**          |                                                                                                                                                                            |
| *      | *Italics*         |                                                                                                                                                                            |
| ==     | ==Highlight==     |                                                                                                                                                                            |
| ~~     | ~~Strikethrough~~ |                                                                                                                                                                            |
| -      | - Bulletpoint     |                                                                                                                                                                            |
| 1.     | 1. Numbered List  |                                                                                                                                                                            |
| ---    | Horizontal Line   | Three dashes turn into a horizontal line after hitting return unless you are trying this on top of a note. Here three dashes will create the designated area for metadata. |
| - [ ]  | Open Task         |                                                                                                                                                                            |
| - [x]  | Done Task         |                                                                                                                                                                            |
| !      | Embed             | See for example the code in the table for callouts below: This is simply a link to a picture with an exclamation mark in front of it.                                      |

#### Callouts

| Win             | Mac       | Action             | Code                          |
| --------------- | --------- | ------------------ | ----------------------------- |
| Alt + Shift + 1 | ⌘ + ⇧ + 1 | Insert Callout (1) | > [!NOTE] Title<br>> Contents |
|                 |           |                    |                               |
To change the type of callout replace "NOTE" within the square brackets behind the exclamation mark with "Abstract", "Info", "Tip" or any of the words in the table below. It will change the appearance accordingly.
