1. Go to Settings / Note Refactor
2. Set as "Default location for new notes": Same folder as current file
3. Leave "File name prefix" and "Note link template" blank.
4. For "Refactored note template" write: 
```
up::{{link}} ({{date:YYYY.MM.DD}})

{{new_note_content}}
```
